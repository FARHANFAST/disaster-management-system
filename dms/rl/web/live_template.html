Building B1 · Q-learning on the navigation graph · grid walker on 0.5 m cells

Evacuees learning their way out

The agents decide on the graph: in each room, door or corridor piece they pick which neighbouring node to head for. A grid walker then walks them there cell by cell, using only the cells of those two nodes, so they leave rooms through doorways and step around furniture. The reward is −seconds actually walked. Each node is coloured by its learned time to an exit (−max Q) once a real route from it is known. Every agent shares one Q-table; each one also has its own sampled walking speed, mobility and reaction time (from its gender, age group and role), which scale its real walk time. The ledger also carries each agent's full cognitive and physiological profile — persona, familiarity, panic threshold, sensing radius, health, stress — shown but not simulated yet. The first floor has no exits, so those agents must learn to take a stair.
